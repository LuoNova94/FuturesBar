# 合约行情 · 股票与 ETF 合约支持

本次包含 Mac 0.1.3 和 Windows 0.2.1 预览版。

- 支持 Binance TradFi USDT 永续合约：KORU、SPCX（SpaceX）、TSLA、NVDA 等交易中的品种。
- 搜索 SpaceX 或 SPCX 均可找到 SPCXUSDT；搜索 KORU 或韩国可找到 KORUUSDT。
- 可与 BTC、ETH 等加密货币永续混合选择，合计最多三个；支持最新成交价和标记价格。

## 下载与安装

- Apple 芯片 Mac、macOS 13+：下载 `FuturesBar-0.1.3-arm64-unnotarized.dmg`，将应用拖入「应用程序」。此版未公证。
- Windows 11 x64：下载 `FuturesBar-0.2.1-win-x64-preview.zip`，完整解压后运行 `FuturesBar.exe`，无需另装 .NET。此版未签名。
- 源码：`FuturesBar-0.2.1-source-preview.zip`，MIT 许可证。
- 校验：`FuturesBar-0.2.1-preview-SHA256SUMS.txt`。

Mac 的 12 项核心检查、弹窗布局检查与 Windows 的 8 项核心检查通过；两端均通过 BTC、KORU、SPCX 最新成交价及标记价格真实推送检查。Windows 新版界面仍需实机验收。

价格为 Binance 合约行情，单位 USDT；不含 USD1、USDC 或交割合约。需要网络能访问 Binance，支持配置本机代理。不需要账号或 API Key。
