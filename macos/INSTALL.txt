合约行情 · FuturesBar

适用：Apple 芯片 Mac（M1 及更新芯片），macOS 13 或更新版本。
本安装包为未公证试用版，使用本机临时签名，没有 Apple Developer ID 签名或 Apple 公证。

安装
1. 将「合约行情.app」拖到旁边的「Applications / 应用程序」。
2. 从「应用程序」打开「合约行情」。价格出现在屏幕右上角菜单栏，点击即可查看面板。
3. 更新时先退出旧版，再替换应用。

首次打开
macOS 可能提示无法验证开发者。如果你确认下载来源可信，可在尝试打开应用后，
进入「系统设置 → 隐私与安全性」，查看对应应用的提示并选择「仍要打开」。
如果系统明确提示恶意软件或文件被篡改，请停止安装。
Apple 官方说明：https://support.apple.com/102445

网络与使用
- 默认跟随 macOS 系统网络设置，需要能够访问 Binance 公共行情服务。
- 如果无法连接，可点击面板下方「网络 · 跟随系统」，开启「手动配置本机代理」，
  填写你自己的 HTTP / 混合代理端口，保存后立即重连。
- 只支持 Binance USDT 永续合约，最多同时显示 3 个品种。
- 不需要 Binance 账号、密码或 API Key，没有交易、持仓或余额查询功能。
- 开机启动可在面板中选择开启。

此包不包含开发者本机的账户信息、偏好设置或代理软件。
