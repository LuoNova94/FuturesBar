# FuturesBar · macOS 菜单栏版

此目录为独立的 Swift 项目，包含源代码、测试、应用配置和构建脚本。

**[Mac 安装、使用、截图与构建说明](../docs/mac.md)**

从仓库根目录执行：

```sh
zsh macos/build.sh
zsh macos/check.sh
zsh macos/check-layout.sh
zsh macos/package-release.sh
```

应用输出为仓库根目录下的 `output/合约行情.app`，构建缓存位于 `macos/.build/`。
