合约行情 Windows 悬浮条 · FuturesBar 0.2.0 预览版

适用：Windows 11 x64。本程序为未签名预览版，尚未完成 Windows 实机界面验收。

1. 先将 ZIP 完整解压到固定文件夹，再运行 FuturesBar.exe，无需另装 .NET。
2. 悬浮条最多显示 3 个品种。拖动行情区域可移动，双击或右键可打开设置。
3. 齿轮打开设置；× 只隐藏悬浮条，程序仍在系统托盘运行。
4. 左键点击右下角托盘图标显示 / 隐藏，右键可设置、重新连接或退出。
5. 设置支持选品种、排序、最新成交价 / 标记价、锁定、置顶、透明度和登录后启动。
6. 默认跟随系统网络；需要时填写自己的本机 HTTP / 混合代理端口。
7. 开机启动启用前，请把程序放在固定位置。移动程序后需重新设置。

本地设置：%LOCALAPPDATA%\FuturesBar\settings.json
不需要 Binance 账号或 API Key。程序只使用公开合约行情，无账户查询或交易功能。
网络需能访问 Binance 行情服务。此版本支持 USDT 永续合约。

Windows 可能显示未知发布者或信誉提示。请只使用自己信任的下载来源。
需要退出时请使用托盘菜单「退出」。更新前先退出旧版。
